## About me

I'm a full-stack developer working where **Web3 security**, **AI agents** and **developer tooling** meet. I build products from start to finish: React and TypeScript frontends, Node and Python APIs, and the LLM logic that ties them together.

- **Currently building** [SignSafeli](https://github.com/AshishChikane/sol-security-transaction). It is a pre-sign transaction firewall for Solana that simulates each transaction, scores its risk with rules plus an LLM, and explains the result in plain English.
- **Shipping Claude Code plugins** for React development, sales prospecting, website audits (SEO / AEO / GEO) and LinkedIn automation.
- **Working on** LLM security, MCP servers, multi-agent workflows and hardened ML pipelines.
- **Background:** 5+ years on GitHub, moving from React dashboards and booking apps to smart contracts, AI agents and security tooling.
